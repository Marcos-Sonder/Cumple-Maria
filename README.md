# 🎂 Cumple-Maria

¡Bienvenido al repositorio del proyecto **Cumple-Maria**! Esta es una página web especial creada para celebrar el cumpleaños de María, compartiendo detalles del evento, fotos y momentos especiales.

## 🚀 Características de la página
*   **Diseño Responsivo:** Se adapta perfectamente a pantallas de celulares, tablets y computadoras.
*   **Multimedia:** Incluye secciones dedicadas para fotos y videos emotivos.
*   **Cuenta regresiva / Invitación:** Información detallada sobre el festejo.

## 🛠️ Tecnologías utilizadas
*   **HTML5:** Para toda la estructura y el contenido de la página.
*   **CSS3:** Para los estilos, colores y animaciones visuales.
*   **JavaScript:** (Opcional, bórralo si no lo usaste) Para los componentes interactivos.
